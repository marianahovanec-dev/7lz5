# Лабораторна робота: Робота зі структурою "Student" через вказівники у C++

## Мета роботи
Описати структуру з іменем `Student`, яка містить поля: ПІБ, номер групи та успішність (середній бал)[cite: 1].Написати програму на мові C++, яка виконує введення даних з клавіатури в масив структур, впорядковує записи за зменшенням середнього бала та виводить на дисплей дані студентів, середній бал яких більший за 4.0[cite: 1].
Закріпити навички роботи з вказівниками на структури та динамічним доступом до їхніх полів.

## Хто виконала
**Виконавча студентка:** Хованець Мар'яна
**Група:** 4 СОМ
## Варіант 1
## Що саме виконує цей код
Ця програма на мові C++ реалізує обробку даних про студентів за допомогою структур та вказівників. Основні етапи її роботи:
1. **Опис структури (`struct Student`):** Створює шаблон даних для збереження інформації про кожного студента, який включає три поля: ПІБ (`pib`), номер групи (`group`) та середній бал (`averageScore`).
2. **Введення даних:** У циклі для 5 студентів програма за допомогою вказівника на структуру (`Student* studentPtr = &students[i]`) зчитує з клавіатури ПІБ, групу та середній бал, використовуючи стрілочний оператор доступу (`->`).
3. **Сортування за зменшенням:** Використовує алгоритм сортування для впорядкування записів у масиві за спаданням середнього бала студентів (від найвищого до найнижчого).
4. **Фільтрація та виведення результатів:** 
   * Виводить відсортований список усіх студентів.
   * Здійснює перевірку та виводить на екран ПІБ і номери груп тих студентів, чий середній бал суворо більший за `4.0`[cite: 1].
   * Якщо таких студентів немає, виводить відповідне сповіщення про їхню відсутність[cite: 1].
